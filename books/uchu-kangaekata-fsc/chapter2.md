> 無関係に、均一に流れる」*

アインシュタインは
この「絶対時間」を
打ち砕いた。

## 2.2 ウィック回転——数学から物理へ

**ウィック回転**は
もともと数学的な技法だ。

量子場理論の計算で、
積分を収束させるために
時間を虚数に置き換える——

```
t → -iτ
（ミンコフスキー時間
  → ユークリッド時間）
```

これは「計算の都合」として
長い間使われてきた。

FSCはこう解釈する——

```
━━━━━━━━━━━━━━━━━━

ウィック回転は
単なる数学的技法ではない。

ブラックホールの
事象の地平面で
物理的に起きている
実在の現象だ。

━━━━━━━━━━━━━━━━━━
```

## 2.3 ブラックホール地平での時間変容

ブラックホールに
近づくと何が起きるか。

遠方の観測者から見ると——
落下する物体の時計は
どんどん遅くなり、
事象の地平面で
**止まる**。

落下する観測者自身から見ると——
地平面を越えた瞬間、
時間と空間の役割が
**入れ替わる**。

```
【地平面の外】          【地平面の内】
時間：過去→未来        時間：空間的方向
空間：3次元            空間：時間的方向
```

FSCはここで問う——

「役割が入れ替わるだけでなく、
時間が**複素数になる**のでは？」

```
地平面での変換：

t → it

実数時間 → 虚数時間
```

## 2.4 複素時間平面 ℂ_t

複素数とは——
実部と虚部を持つ数だ。

```
z = a + bi
（a：実部、b：虚部、i：虚数単位）
```

時間を複素数として扱うと——
**複素時間平面**ができる。

```
複素時間平面 ℂ_t

                           ↑ 虚数時間（it）
                           │
                           │   Sector-II
                           │   暗黒物質世界（27%）
                           │   （虚数時間領域）
                           │
負の実数時間（-t）←──────────┼──────────→ 実数時間（t）
                           │
Sector-III                 │            Sector-I       
暗黒エネルギー世界           │            私たちの宇宙（バリオン）
（逆時間領域）（68%）        │            （実数時間領域）(5%)
                           │            
                           │
                           │   Sector-IV
                           │   CPT共役世界（崩壊済み、≈0%）
                           ↓ 負の虚数時間（-it）
```

この平面上に
4つのセクターが広がる。

問い： なぜ Sector I は 5% しかないのに 我々はそこに住むのか

答え： 宇宙の初期状態では 4セクターは等しく 25% だった。
　　　 Sector IV が崩壊し—— その一部（5%）が 
　　 　Sector I（バリオン）に 転換した。
　　 　残りの 95% は Sector II・III に 分配された。 
　　 　我々は—— 「崩壊の残滓」の 中に生きている。

**しかし—— その 5% の中にのみ 星が生まれ、 惑星が形成され、 生命が宿り、 宇宙を問う者が現れた。**

## 2.6 時間の矢はなぜ一方向か

私たちは——
過去を覚えているが
未来は覚えていない。

コーヒーは冷めるが
温まりはしない。

これを**時間の矢**という。

FSCでは——

```
━━━━━━━━━━━━━━━━━━

時間の矢の定義：

t₂ > t₁
⟺
S(t₂) ≥ S(t₁)

時刻 t₂ が t₁ より「後」
であることは——
エントロピーS が
増大していることと
同値だ。

━━━━━━━━━━━━━━━━━━
```

時間はエントロピーの
「順序付きラベル」だ。

Sector-I（私たちの宇宙）では
エントロピーが増大するため、
時間の矢が+t 方向に向く。

Sector-III（逆時間領域）では
時間の矢が -t 方向——
つまり私たちとは
逆向きになる。

## 2.7 ブラックホール特異点での時間回転

最も劇的な変換が起きるのは
ブラックホールの
**特異点**だ。

```
ブラックホール特異点での変換：

+t → it → -t

実数時間
→ 虚数時間（地平面通過）
→ 逆実数時間（特異点通過）
```

これが——

```
Sector-I → Sector-II → Sector-III
```

への接続だ。

ブラックホールは
単なる「穴」ではない。

**異なる時間位相のセクターへの
入口**だ。

## 2.8 循環宇宙——時間の2π回転

複素時間平面を
一周（2π回転）すると——

```
Sector-I → Sector-II
→ Sector-III → Sector-IV
→ Sector-I（次のサイクル）
```

宇宙は**循環する**。

```
━━━━━━━━━━━━━━━━━━

前のサイクルの
高エントロピー状態が——

次のサイクルの
低エントロピー初期条件を
生成する。

これがペンローズの
「特殊な初期条件問題」
（e^{-10^{123}}）への
自然主義的解答だ。

━━━━━━━━━━━━━━━━━━
```

## 2.9 数学的補足：複素数と虚数単位

*（数式が初めての方へ）*

**虚数単位 i** とは——

```
i² = -1

を満たす数。

実数の中には存在しないが、
数学的に一貫した体系を作る。
```

**複素数** z とは——

```
z = a + bi

a：実部（Real part）
b：虚部（Imaginary part）
i：虚数単位
```

**複素平面**とは——

```
横軸：実部 a
縦軸：虚部 b

任意の複素数は
この平面上の1点として
表せる。
```

FSCでは——
この複素平面の**横軸**が
「実数時間」、
**縦軸**が
「虚数時間」に対応する。
