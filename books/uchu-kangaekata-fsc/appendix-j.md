## §2 定理 TS-O-1：時間–パラメータ双対性

### 3つのスケーリング指数の定義

| 指数    | 定義                                                | 値           | 出典                   |
| ------- | --------------------------------------------------- | ------------ | ---------------------- |
| α       | d ln Ω_{IV}/d ln τ（時間軸の収束指数）              | 0.527        | Paper O, Thm O-4       |
| α_c     | d ln c/d ln Ω_M（パラメータ空間のスケーリング指数） | 0.417 ≈ 5/12 | Paper T, Thm T-5/12    |
| **α_J** | −d ln J_first/d ln Ω_M（新たな橋渡し指数）          | **0.373**    | Paper TS-O, Lem TS-O-1 |

**α_J の導出（補題 TS-O-1）**：

J_first = (2/3)·arcsinh(√R)/√Ω_Λ を Ω_M で微分すると：

```
d ln J/d ln Ω_M = 1/(2R) − √(1+R)/(2√R)
```

よって α_J = (√(R(1+R)) − 1)/(2R) = (2.607 − 1)/4.308 = **0.373**（R = 2.154 で）

### 定理 TS-O-1（時間–パラメータ双対性）

3つの指数はすべて **J_first(Ω_M) という単一の関数** から派生しており、以下の双対関係を満たす：

```
α_J = (α + α_c)/2 × (1 − δ_dual)

δ_dual = 1 − 2α_J/(α + α_c) ≈ 0.21
```

- 数値確認：(α + α_c)/2 = (0.527 + 0.417)/2 = 0.472
- α_J/0.472 = 0.373/0.472 = 0.790 = 1 − 0.210

**非対称性 δ_dual の起源**：α に含まれる音響結合因子 (√3−1)/(2e) ≈ 0.239（c_s = 1/√3 と Hubble e-fold をコード化）が α_c, α_J には存在しないことによる。

### 系 TS-O-1a（指数和による物質密度の決定）

平坦性条件 Ω_M + Ω_Λ = 1 のもとで：

```
┌──────────────────────────────────┐
│  α + α_c + α_J = 1 + Ω_M + O(ε_O, δ²)  │
└──────────────────────────────────┘
```

数値確認：

| 0.527 | 0.417 | 0.373 | **1.317** | **1 + 0.317 = 1.317** |

誤差：ゼロ（機械的一致）

**物理的意味**：「1」は平坦性条件 Ω_M + Ω_Λ = 1 が R = Ω_Λ/Ω_M を通じて3つの指数すべてに埋め込まれていることから生じる。

## §3 定理 TS-O-2：自己整合的物質密度 Ω_M^{**} = 0.31694

