**Λ-CDM**と呼ばれる。

「CDM」は冷たい暗黒物質
（Cold Dark Matter）を意味する。

Λ-CDMは驚くほど成功している。

```
【Λ-CDMが説明できること】

・宇宙マイクロ波背景放射（CMB）
  の温度ゆらぎ
・銀河の大規模構造
・バリオン音響振動（BAO）
・宇宙の加速膨張
・軽元素の存在比（BBN）

→ 6つのパラメータで
  約40の観測量を精密に記述
```

しかし——

Λ-CDMは
**「なぜ」に答えない。**

## 1.3 FSCの基本アイデア

FSCの出発点は
シンプルだ。

```
━━━━━━━━━━━━━━━━━━

「時間は実数だけではない」

━━━━━━━━━━━━━━━━━━
```

通常の物理学では
時間 t は実数だ。
過去から未来へ
一方向に流れる。

FSCはこう問う——

*「ブラックホールの
地平（事象の地平面）を
越えたとき、
時間はどうなるか？」*

答え：
**時間が虚数に変わる。**

```
t → it
（実数時間 → 虚数時間）
```

これを**ウィック回転**という。

そして——
虚数時間の先には
さらに**逆時間**（-t）が、
その先には
**CPT共役時間**（-it）がある。

```
複素時間平面 ℂ_t

        it（Sector-II）
            ↑
    -t ←────┼────→ +t
Sector-III  │  Sector-I
            ↓
       -it（Sector-IV）
```

これが**四つのセクター**だ。

## 1.4 Z₄対称性とCPT

四つのセクターは
対称性で結ばれている。

**Z₄対称性**とは——
90°回転の対称性だ。

```
Sector-I  → Sector-II → Sector-III → Sector-IV → Sector-I
   +t     →    it     →    -t      →    -it    →    +t
          （90°回転）
```

そして**CPT対称性**とは——
電荷（C）、
空間（P）、
時間（T）を
同時に反転させると
物理法則が変わらない、
という対称性だ。

```
FSCの根本原理：

Z₄ × CPT

この対称性ひとつから
宇宙のすべてが導かれる。
```

## 1.5 「自由パラメータ ゼロ」とはどういう意味か

Λ-CDMには
6つの自由パラメータがある。

```
【Λ-CDMの自由パラメータ】

H₀   ハッブル定数
Ω_b  バリオン密度
Ω_DM 暗黒物質密度
A_s  原始ゆらぎの振幅
n_s  スペクトル指数
τ    再電離光学的深さ

→ 観測データに合わせて
  調整する「つまみ」
```

FSCには
このような「つまみ」がない。

全ての値が
Z₄ × CPT 対称性から
**論理的に導かれる。**

:::message
**【「ゼロ自由パラメータ」の留保事項】**

FSC が「自由パラメータ ゼロ」と主張するとき、正確には次の意味です：

- 宇宙組成 (Ω_b, Ω_DM, Ω_Λ) = (5%, 27%, 68%) は Z₄ × CPT から導出 ✓
- 崩壊定数 λ_IV は Sector-IV の量子場論的性質から決まる ✓
- **ただし：** Sector-IV 崩壊の微視的場の結合定数 λ（スケールオーダー √λ ∼ 10⁻²）は
  現時点では概算値です。厳密な第一原理導出は進行中の研究課題です。

「ゼロ自由パラメータ」は**マクロな宇宙組成レベルでの主張**です。
微視的場の定数については引き続き精密化が必要です。
:::

```
━━━━━━━━━━━━━━━━━━

たとえば——

Ω_b : Ω_DM : Ω_Λ = 5:27:68

これはFSCでは
「観測値」ではなく
「導出値」だ。

Sector-IV の崩壊速度と
ワームホール転送関数から
計算される。

━━━━━━━━━━━━━━━━━━
```

これは——

ニュートンが
リンゴの落下と
月の公転を
同じ「重力」で説明したときと
同じ種類の驚きだ。

別々に見えていたものが
ひとつの原理から
導かれる。
