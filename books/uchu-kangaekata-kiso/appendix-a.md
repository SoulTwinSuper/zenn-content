## ア行

---

```
【暗黒エネルギー（Dark Energy）】
宇宙の加速膨張を引き起こす
正体不明のエネルギー。
宇宙全体の68%を占める。
アインシュタインの宇宙定数Λと
関連する可能性がある。
→ 第1章1-3参照

【暗黒物質（Dark Matter）】
重力は持つが光と反応しない
正体不明の物質。
宇宙全体の27%を占める。
銀河の回転速度の観測から
存在が示唆されている。
→ 第1章1-2参照

【ウィック回転（Wick Rotation）】
時間tを虚数時間itに
置き換える数学的操作。
t → it
複素平面上での90度回転に対応。
FSCではブラックホール地平線での
物理的遷移として解釈される。
→ 第4章4-6参照

【エントロピー（Entropy）】
系の「乱雑さ」「無秩序さ」の度合い。
熱力学第二法則により——
孤立系のエントロピーは
増大する方向にしか変化しない。
時間の矢の起源とされる。
→ 第2章2-4参照
```

## カ行

---

```
【関係的時間（Relational Time）】
時間を「変化の順序付きラベル」
として捉える考え方。
ライプニッツに起源を持ち——
「変化がなければ時間はない」
という立場。
FSCの時間観の基礎。
→ 第2章2-5参照

【宇宙定数（Cosmological Constant）Λ】
アインシュタインが
重力方程式に導入した定数。
当初は「静的宇宙」を保つために
導入されたが、後に撤回。
現代では暗黒エネルギーの
候補として再注目されている。
→ 第1章1-3参照

【CPT対称性】
電荷共役（C）・パリティ（P）・
時間反転（T）の三変換を
同時に行っても
物理法則が変わらないという対称性。
現代物理学の最も基本的な対称性の一つ。
FSCでもCPT対称性は保持される。
→ 第3章3-5参照

【CP対称性の破れ】
物質と反物質が
わずかに異なる振る舞いをする現象。
1964年にK中間子の崩壊で発見。
バリオン非対称の原因の一つ。
Sakharov三条件のS2に相当。
→ 第3章3-4参照
```

## サ行

---

```
【Sakharov三条件】
バリオン非対称が生まれるために
必要な三つの条件。
1967年にアンドレイ・サハロフが提唱。

S1：バリオン数非保存
S2：C対称性とCP対称性の破れ
S3：熱平衡からの逸脱

→ 第3章3-6参照

【四セクター複素時間宇宙論（FSC）】
Four-Sector Complex Time Cosmology。
複素時間の四象限を
宇宙の四つの「相」に対応させる
宇宙論モデル。
片倉慶孝とアインシュタイン（AI）の
共同研究として発展。
→ 第4章全体参照

【循環宇宙（Cyclic Universe）】
宇宙が一度限りでなく——
サイクルを繰り返すという仮説。
FSCでは四セクターの2π回転が
一つのサイクルを構成する。
前サイクルの高エントロピーが
次サイクルの低エントロピー
初期条件を生成する。
→ 第4章4-8参照
```

## タ行

---

```
【対称性の破れ（Symmetry Breaking）】
ある変換に対して
法則や状態が変化すること。
FSCでは——
初期宇宙のZ4対称性（25%×4）が
動的に破れることで
現在の5:27:68が生まれる。
→ 第3章3-7・第4章4-4参照

【時間の矢（Arrow of Time）】
時間が「過去から未来へ」
一方向に流れることを指す概念。
物理法則は時間対称だが——
エントロピーの増大が
方向性を与える。
→ 第2章2-4参照

【特殊相対性理論
（Special Theory of Relativity）】
1905年にアインシュタインが発表。
「光速は誰から見ても同じ」を
基本原理とし——
時間と空間が観測者によって
変化することを示した。
「E=mc²」はこの理論から導かれる。
→ 第2章2-3参照
```

## ナ行

---

```
【ネーターの定理（Noether's Theorem）】
数学者エミー・ネーターが1915年に証明。
「物理法則に対称性があれば——
　対応する保存則が存在する」
空間並進対称性→運動量保存
時間並進対称性→エネルギー保存
回転対称性→角運動量保存
→ 第3章3-1参照
```

## ハ行

---

```
【バリオン（Baryon）】
陽子・中性子などの
重い素粒子の総称。
通常物質の主成分。
宇宙全体の5%を占める。
→ 第1章1-4参照

【バリオン非対称
（Baryon Asymmetry）】
宇宙に物質（バリオン）が
反物質より多く存在する現象。
光子10億個につき
バリオン約6個の割合。
η_b ≈ 6.1×10⁻¹⁰
→ 第1章1-4・第3章3-6参照

【ビッグバン元素合成（BBN）】
Big Bang Nucleosynthesis。
ビッグバンから数分後——
宇宙の温度が下がる中で
水素・ヘリウム・リチウムなどの
軽元素が合成された過程。
η_b の値はBBNの観測から
精密に測定されている。

【複素数（Complex Number）】
実数と虚数を合わせた数。
a + bi の形で表される。
（a：実数部、bi：虚数部、
　i：虚数単位、i²= -1）
量子力学・電気工学など
現代科学に不可欠な概念。
→ 第2章2-6参照

【複素時間（Complex Time）】
時間が実数だけでなく
複素数として振る舞う可能性。
FSCの核心的概念。
虚数時間への移行（ウィック回転）が
暗黒物質・暗黒エネルギーとの
繋がりを示唆する。
→ 第2章2-6・第4章参照
```

## ヤ行・ラ行

---

```
【η_b（バリオン-光子比）】
eta_b と読む。
バリオン数密度と
光子数密度の比。
η_b = n_b / n_γ ≈ 6.1×10⁻¹⁰
BBNとCMB観測から精密測定。
FSCはこの値を
自由パラメーターなしに導出する。
→ 第1章1-4・第4章4-5参照

【Z4対称性】
90度回転を4回繰り返すと
元に戻る対称性。
四回回転対称性とも呼ぶ。
FSCの初期状態（25%×4）が
持つ対称性。
→ 第4章4-4参照
```
