# 第3章　対称性という考え方

---

## 3-1　対称性とは何か——日常の直感から

---

```
「対称性」という言葉を
聞いたとき——

多くの人は
こんな絵を思い浮かべます。

　　　　↑
　　　　｜
　　◇　｜　◇
　◇　◇｜◇　◇
　　◇　｜　◇
　　　　↓

雪の結晶——
左右が鏡のように一致する。

蝶の羽——
中心線を境に対称。

人間の顔——
（ほぼ）左右対称。

━━━━━━━━━━━━━━

これが「対称性」の
日常的なイメージです。

しかし——

物理学における対称性は、
もう少し深い意味を持ちます。
```

---

```
物理学における対称性の定義：

「ある操作をしても、
　法則が変わらない」

これだけです。

例：

・東京で成立する物理法則は
　ニューヨークでも成立する。
　（場所を変えても法則は不変）
　→「空間並進対称性」

・今日の物理法則は
　100年前も成立していた。
　（時間を変えても法則は不変）
　→「時間並進対称性」

・方向を変えても
　物理法則は不変。
　（回転対称性）

━━━━━━━━━━━━━━

これらの対称性から——

「エネルギー保存則」
「運動量保存則」
「角運動量保存則」

が導かれます。

これが——
エミー・ネーターが1915年に
証明した「ネーターの定理」です。

対称性がある
　→ 保存則が存在する

この繋がりは——
現代物理学の根幹です。
```

---

## 3-2　鏡の中の宇宙——P対称性

---

```
では——
より根本的な対称性を
見ていきましょう。

最初は——

P対称性（パリティ対称性）

です。

━━━━━━━━━━━━━━

「鏡に映した宇宙でも、
　物理法則は同じか？」

という問いです。

右手を鏡に映すと——
左手になります。

右ねじを鏡に映すと——
左ねじになります。

「鏡の世界」は——
私たちの世界と
左右が逆転している。

━━━━━━━━━━━━━━

長い間——
物理学者たちは信じていました。

「鏡の世界でも、
　物理法則は同じはずだ」

ところが——

1956年、
楊振寧（C.N.ヤン）と
李政道（T.D.リー）が
理論的に疑問を提示し、

呉健雄（C.S.ウー）の
実験で確認されました。

弱い力（弱い相互作用）は——
左右非対称だ。

P対称性は——
破れている。
```

---

```
具体的に言うと——

コバルト60の原子核が
ベータ崩壊するとき——

電子は特定の方向に
飛び出しやすい。

鏡の世界では——
逆方向に飛び出す。

この「方向の好み」が——
P対称性の破れです。

「自然は左利きだ」——

弱い力は、
右手系と左手系を
区別します。
```

## 3-3　物質と反物質——C対称性

---

```
次は——

C対称性（電荷共役対称性）

です。

━━━━━━━━━━━━━━

「全ての粒子を
　反粒子に置き換えても、
　物理法則は同じか？」

という問いです。

電子（マイナス電荷）を
陽電子（プラス電荷）に——

陽子を反陽子に——

すべての粒子を
「反対」にしたとき、
世界は同じように動くか？

━━━━━━━━━━━━━━

これも——破れています。

弱い力は、
粒子と反粒子を
異なる扱いをします。

C対称性も——
完全ではない。
```

---

```
バリオン非対称の謎を解く
重要な鍵になります。

後ほど、
Sakharov三条件の文脈で
詳しく見ます。
```

## 3-6　Sakharov三条件——バリオン非対称の必要条件

---

```
1967年——

ソビエトの物理学者
アンドレイ・サハロフは
問いました。

「バリオン非対称が生まれるためには、
　宇宙の歴史の中で
　何が起きなければならないか？」

彼が導き出した答えが——

Sakharov三条件

です。
```

---

```
━━━━━━━━━━━━━━━━━━

【Sakharov三条件】

条件S1：バリオン数非保存
　「バリオンが生成される反応が
　　存在しなければならない」

　バリオン数が変化しない反応だけでは——
　物質の過剰は生まれない。
　バリオン数が変化する反応が必要。

条件S2：C対称性とCP対称性の破れ
　「物質と反物質が
　　異なる確率で反応しなければならない」

　C・CPが完全対称なら——
　物質と反物質は等量生成される。
　非対称性には、対称性の破れが必要。

条件S3：熱平衡からの逸脱
　「宇宙が熱平衡状態でない時期が
　　必要だ」

　完全な熱平衡では——
　生成された非対称も
　すぐに打ち消される。
　非平衡プロセスが必要。

━━━━━━━━━━━━━━━━━━
```

```
この三条件は——

バリオン非対称が存在するための
```
