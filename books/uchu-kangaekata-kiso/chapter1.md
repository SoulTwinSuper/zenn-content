# 第1章　宇宙の三つの謎

---

## 1-1　宇宙の「中身」を知っていますか

---

```
突然ですが、問いを一つ。

「宇宙は何でできていますか？」

多くの人は答えます——
「星や銀河でしょう」と。

正解です。
しかし——

それは宇宙全体の
たった5%にすぎません。

残りの95%は、
私たちがまだ正体を知らない
何かでできています。
```

---

```
宇宙の組成：

━━━━━━━━━━━━━━━━━━
通常物質（バリオン）  ：  5%
━━━━━━━━━━━━━━━━━━
暗黒物質             ： 27%
━━━━━━━━━━━━━━━━━━
暗黒エネルギー       ： 68%
━━━━━━━━━━━━━━━━━━

この数字は——
NASAでもESAでも
どこに聞いても同じです。

Planck衛星が
精密に測定した数字です。

つまり——

私たちが「見ている」宇宙は、
宇宙全体の5%に
すぎない。
```

---

```
これが——
本章で扱う
「三つの謎」の出発点です。

謎① なぜ27%が「暗黒物質」なのか
謎② なぜ68%が「暗黒エネルギー」なのか
謎③ なぜ5%の物質が存在するのか

一つずつ、見ていきましょう。
```

---

## 1-2　謎①　暗黒物質——見えない重力の正体

---

```
1930年代。

スイスの天文学者
フリッツ・ツビッキーは
奇妙なことに気づきました。

銀河団の中の銀河が——
速く動きすぎている。

ニュートンの重力法則で計算すると、
あの速さで動くためには、
見えている物質の
400倍以上の重さが必要です。

しかし——
見える物質の量は足りない。

では、何が
重力を生み出しているのか。
```

---

```
現代でも、同じ謎が残っています。

銀河の回転速度を測ると——
外側の星が
「速く回りすぎている」のです。

見えている物質だけでは、
あの速さで星が
飛び出さずに回り続ける
説明ができません。

何か見えない物質が、
重力を生み出している。

それが——「暗黒物質」です。

━━━━━━━━━━━━━━

暗黒物質の特徴：

・重力は持つ
・光を出さない（見えない）
・光を吸収もしない（透明）
・電磁気力と反応しない
・正体は不明

━━━━━━━━━━━━━━

宇宙の27%が
この「見えない何か」です。

正体を巡って——
物理学者たちは今も
議論を続けています。
```

## 1-3　謎②　暗黒エネルギー——宇宙を加速させる力

---

```
1998年。

二つの研究チームが
同時に、驚くべき発見をしました。

宇宙は——
加速しながら膨張している。

常識では——
膨張は減速するはずです。
ビッグバンの爆発力が
重力に引き戻されるから。

しかし現実は逆でした。

宇宙は、まるで
見えない力に押されるように、
どんどん速く広がっている。

この発見で、
ソール・パールマッター、
ブライアン・シュミット、
アダム・リースの三人は
2011年にノーベル物理学賞を
受賞しました。

━━━━━━━━━━━━━━

この「加速膨張を引き起こす
見えないエネルギー」を——

暗黒エネルギーと呼びます。

宇宙の68%が
これでできています。

しかし——
その正体は、
ほとんどわかっていません。
```

---

```
私（アインシュタイン）には
この謎と
奇妙な縁があります。

1917年——
私は「宇宙定数Λ」という
項を方程式に加えました。

当時、宇宙は静止していると
思われていたので——
重力に対抗して
宇宙を安定させるために
付け加えた「補正項」です。

しかし後に
宇宙が膨張していることが
わかり——

私はこれを
「生涯最大の過ち」と
呼びました。

ところが——

現代物理学では、
この宇宙定数Λが
暗黒エネルギーの候補として
再び注目されています。

「過ち」が——
謎の鍵かもしれない。

科学とは、
こういうものです。
```

## 1-4　謎③　バリオン非対称——なぜ物質があるのか

---

```
三つの謎の中で——
私が最も深いと思うのが、
これです。

なぜ、宇宙に物質があるのか。

物理法則は——
物質と反物質を
対称に扱います。

電子があれば陽電子がある。
陽子があれば反陽子がある。

ビッグバンの瞬間——
物質と反物質は
ほぼ同じ量だけ生まれた
はずです。

「ほぼ」——がすべての鍵です。
```

---

```
光子10億個に対して——
バリオン（物質の素粒子）が
1個だけ多かった。

この「10億分の1」の非対称が
宇宙の運命を決めました。

物質と反物質が出会うと——
対消滅します。
光（エネルギー）に変わります。

もし完全に対称だったら——
すべて打ち消し合い、
光だけの宇宙になった。

星も、地球も、生命も——
存在しなかった。

━━━━━━━━━━━━━━

では、なぜ
「1個だけ多かった」のか。

この「非対称の起源」を説明する
理論を——

バリオン生成（Baryogenesis）
と呼びます。

━━━━━━━━━━━━━━

数値で表すと：

η_b = バリオン数 / 光子数
    ≈ 6.1 × 10⁻¹⁰

（光子10億個につき
　バリオン約6個）

この値は——
ビッグバン元素合成（BBN）と
CMB（宇宙マイクロ波背景放射）の
観測から精密に測定されています。

「なぜη_b = 6.1×10⁻¹⁰なのか」——

これが、実践編-1が
正面から向き合った問いです。
```
