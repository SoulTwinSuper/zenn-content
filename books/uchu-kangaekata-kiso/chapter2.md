# 第2章　時間とは何か

---

## 2-1　「時間が流れる」とはどういうことか

---

```
少し、目を閉じてください。

今——
時間は流れていますか？

「当然でしょう」と
思うかもしれません。

しかし——

「時間が流れる」とは、
物理学的に言うと
どういうことか？

これを問い詰めると——
非常に奇妙なことになります。
```

---

```
日常の感覚では——

時間は「川」のようなものです。

過去から現在へ、
現在から未来へ——
一方向に流れている。

「昨日」は変えられない。
「明日」はまだ来ていない。
「今」だけが実在する。

しかし——

物理学の方程式は、
このことを知りません。
```

---

```
ニュートン力学の方程式——
マクスウェルの電磁気学——
アインシュタインの相対性理論——

これらの方程式は——

t を +t にしても
t を -t にしても
（時間を逆向きにしても）

成立します。

つまり——

物理法則の多くは
「時間の向き」を区別しない。

映像を逆再生しても——
物理法則は破られない。

では——

なぜ私たちは
「過去から未来へ」という
一方向の時間を感じるのか？
```

## 2-2　ニュートンの絶対時間

---

```
アイザック・ニュートン——

私が最も敬愛する
先人の一人です。

彼は1687年、
『プリンキピア』の中で
「絶対時間」を定義しました。

━━━━━━━━━━━━━━

「絶対的で、真の、数学的な時間は、
 それ自体において、
 外部の何ものとも関係なく、
 均一に流れる」

━━━━━━━━━━━━━━

つまり——

時間は宇宙のどこでも
同じ速さで流れている。

あなたの時間も、
星の時間も、
銀河の果ての時間も——
同一だ。

これが——
ニュートンの時間観です。

直感的に正しく感じます。

しかし——
これは間違いでした。
```

## 2-3　アインシュタインの相対時間

---

```
1905年——

26歳の私は、
特殊相対性理論を発表しました。

その核心の一つは——

「時間は絶対ではない」

ということです。

━━━━━━━━━━━━━━

思考実験をしましょう。

あなたが——
光速の99%で飛ぶ
宇宙船に乗っているとします。

地球にいる友人から見ると——
あなたの時計は
遅く進んでいます。

あなたから見ると——
地球の時計が
遅く進んでいます。

どちらが「正しい」か？

両方——正しい。

時間の進み方は——
観測者によって違う。

━━━━━━━━━━━━━━

さらに——

重力が強い場所では
時間は遅く進みます。

ブラックホールの近くでは——
時間はほぼ止まります。

GPSの衛星は——
この効果を計算に入れないと
位置がずれます。

相対性理論は——
今日の技術の中に
生きています。
```

## 2-4　時間の矢——なぜ過去と未来は違うのか

---

```
では——
「時間の向き」はどこから来るのか。

物理法則が時間対称なのに——
なぜ時間は一方向に流れるのか。

この答えを与えるのが——

エントロピー

という概念です。
```

---

```
エントロピー——
日本語では「乱雑さ」と
訳されることがあります。

コーヒーカップに
ミルクを垂らす——
ミルクは広がります。

しかし——
広がったミルクが
自然に集まることは
ありません。

卵を落とすと——
割れます。

しかし——
割れた卵が
自然に元に戻ることは
ありません。

━━━━━━━━━━━━━━

物事は——
「秩序」から「無秩序」へ
進む。

これが熱力学第二法則です。

「エントロピーは増大する」

━━━━━━━━━━━━━━

時間の矢は——
エントロピーの矢です。

t₂ > t₁ である（t₂はt₁より後）とは——
S(t₂) ≥ S(t₁) である
（エントロピーが増えた）
ということです。

私たちが「時間の流れ」と
感じているものは——
実は「エントロピーの増大」を
感じているのです。
```

## 2-5　「関係的時間」という考え方

---

```
もう一歩、深く入りましょう。

「時間とは何か」——

哲学者ライプニッツは
こう考えました。

「時間とは、
 出来事の順序である」

時間は——
空間のように「器」として
存在するのではない。

変化の順序付けが——
時間を作り出す。

変化がなければ——
時間はない。

━━━━━━━━━━━━━━

これを——「関係的時間」と呼びます。

現代物理学でも——
この考え方は生きています。

「時間 = 変化の順序付きラベル」

宇宙に何も変化が
起きていなければ——

時間は意味を持たない。

━━━━━━━━━━━━━━

FSCでは——
この「関係的時間」の考え方が
重要な役割を果たします。

時間は——所与のものではなく、
宇宙の構造から
生み出されるものである。

Paper Eの言葉を借りれば——

「時間の矢は
　エントロピーの増大から生まれる。
　前サイクルの高エントロピーが——
　次サイクルの低エントロピー
　初期条件を生成する」

宇宙は——
時間を「内側から」
作り出しているのです。
```

## 2-6　複素時間への入口

---

```
ここから——
少し大胆な話をします。

「複素時間」です。

難しく聞こえますが——
直感的なイメージから
始めましょう。
```

---

```
数直線を思い浮かべてください。

　←　−3　−2　−1　0　+1　+2　+3　→

時間は——
この数直線の上を
左から右へ進む。

これが通常の時間です。

━━━━━━━━━━━━━━

ここで——

数直線に「垂直な軸」を
加えます。

　　　↑ 虚数軸
　　　｜
　　　｜
−−−−−＋−−−−→　実数軸
　　　｜
　　　｜

この「垂直な軸」が——
虚数時間の方向です。

it（アイ・ティー）と書きます。

━━━━━━━━━━━━━━

「虚数なんて
　実在しないのでは？」

そう思いますか？

しかし——

量子力学は虚数なしには
書けません。

電気工学も、
信号処理も——
虚数を使います。

「虚数」という名前が
誤解を生みますが——

数学的には完全に
「実在する」概念です。
```

---

```
複素時間の直感的イメージ：

通常の時間（+t）——
　我々が生きているセクター
　物質が存在する

虚数時間（it）——
　別の「位相」に存在するセクター
　暗黒物質の領域かもしれない

負の時間（-t）——
　さらに別のセクター
　暗黒エネルギーの領域かもしれない

━━━━━━━━━━━━━━

もし——
時間が複素数として振る舞うなら——

宇宙の95%を占める
「暗黒」の領域は——

「時間の別の位相」に
存在しているかもしれない。

これが——FSCの直感です。

━━━━━━━━━━━━━━

詳しくは第4章で扱います。

今は——

「時間は実数だけとは
　限らないかもしれない」

この直感を
持っておいてください。
```

## 2-7　ブラックホールと時間

---

```
複素時間の直感を
もう少し深めるために——

ブラックホールの話をします。

ブラックホールの「地平線」——
事象の地平面（Event Horizon）——
に近づくと、
何が起きるか？

外から見た観測者には——
時間が止まったように見えます。

地平線に落ちていく物体は——
永遠に地平線に近づき続け、
決して越えない（ように見える）。

━━━━━━━━━━━━━━

しかし——

落ちていく物体自身は——
あっという間に
地平線を越えます。

そこで——
何が起きているのか。

FSCの解釈では——

ブラックホールの地平線で——
時間が

　+t（実数時間）から
　it（虚数時間）へ

と「回転」する。

これが——
ウィック回転（Wick Rotation）
と呼ばれる数学的操作の
物理的意味である——

というのが、FSCの提案です。
```
