# 第5章　一次文献を読む順番と、確認の印

> **この章で学ぶこと**
> 1. 主張ごとに、**確認の深さ**を印で示す
> 2. 読む順番：**要旨→本文の表→本文**
> 3. **検索の要約や AI の回答は、論文を超えることがある**

---

## 5-1　なぜ印を付けるのか

整理型の論文の価値は、「どこまで信じてよいか」を、読む人が判断できることです。そのために、**主張ごとに、どこまで確かめたかを示します。**

IN-01 は、各表の数値に「確認済み／二次情報／記憶」を付けました。IN-02 では、これを 5 つの印に整えました。

| 印 | 意味 |
|---|---|
| 【本】 | **本文を読んで**確認した |
| 【要】 | **要旨だけ**確認した（本文は未読） |
| 【自】 | **自前の計算**（スクリプトで再現できる） |
| 【記】 | **記憶・二次情報**（原典を確認していない） |
| 【IN】 | 前の論文（IN-01）で確認した数値 |

この印があると、読む人は、【記】の主張を、**そのまま信じなくて済みます。** そして、書く側は、**【記】を【要】へ、【要】を【本】へ上げる作業**が、はっきりします。

---

## 5-2　読む順番

一次文献は、次の順番で読みました。

1. **要旨（arXiv の abs ページ）。** 何を主張し、どんな数値が出ているかを、つかむ。
2. **本文の表と式。** 数値が、要旨にしか出ていないなら、要旨のまま使う。本文の表に出ているなら、**表の値**を使う。
3. **本文。** 前提、仮定、限界、他の論文への言及を読む。

**要旨と表では、値が違うことがあります。** たとえば、ACT DR6 の要旨は n_s = 0.974 ± 0.003 と丸めて書き、本文の表は 0.9743 ± 0.0034 でした。両方を書いておくと、他の論文の値と照合するときに、迷いません。

---

## 5-3　検索の要約は、論文を超えることがある

調査に、検索や AI の要約を使うことは、便利です。しかし、**要約は、論文に書かれていないことまで言う**ことがあります。IN-02 の制作中に、3 つの例がありました。

### 例 1：検索の要約と、要旨の違い

DESI の BAO の LRG に関する論文（arXiv:2508.10514）について、検索の要約は、「LRG1 と LRG3+ELG1 の BAO 点が、Planck の Ω_m から外れる」と述べました。

しかし、**要旨を読むと**、この論文は「動的暗黒エネルギーの選好は、主に LRG1-2 から来る」と述べるだけで、**LRG3+ELG1 にも、Planck の Ω_m にも、触れていません。** 要約が、別の論文の記述と混ざっていたようです。

### 例 2：外部の AI の回答

CCC（共形循環宇宙）の文献について、外部の AI の検索の回答を貼っていただきました。4 本の論文は、**すべて実在しました**。しかし、1 本ずつ要旨で確認すると、次の違いがありました。

- 題名が、少し違った（"Apparent evidence for Hawking points in the CMB Sky" が正しい）
- 「高確率で発見したと報告」と書かれていたが、**要旨には有意度の数値がない**（99.98% という数字は、別の論文が要約したもの）
- 「第三者によるレビュー」とされた論文は、要旨は「小さな変更を提案」と述べ、**著者の立場も確認できなかった**
- 「レシプロシティ仮説」という語は、**要旨にない**

そして、**この回答には、反論の論文が抜けていました**（第 8 章）。

### 例 3：書誌の食い違い

もう 1 つ、ある論文の書誌が「48(1519)」と紹介されました。Crossref で調べると、**巻 48、1177〜1190 頁**でした。**書誌は、一次の記録（Crossref、出版社）で確認します。**

:::message
**教本ネタ #61　「検索の要約は、論文を超えることがある」**
実在する論文でも、要約の説明には、**足されたもの、抜けたもの、混ざったもの**があります。引用する前に、**要旨で、1 本ずつ**確かめます。
:::

## 5-4　PDF から数式が抜ける

本文を読むために、PDF をテキストに変換すると、**数式が欠ける**ことがあります。IN-02 では、エキピロティックの総説の式（f_NL の式 109 など）が、一部欠けました。不等号の向きも、落ちていました（f_NL ≈ −40 の「≈」か「≲」か）。

**最初の対処：** 欠けた数式の係数は、**本文の文章で述べられた範囲だけ**を書き、「抽出で欠落、原文で要確認」と注記しました。**数式を、推測で補ってはいけません。**

**より良い対処：arXiv の TeX ソースを読む。** arXiv は、多くの論文について、**PDF ではなく、元の LaTeX のソース**（e-print）を公開しています。表と式は、**ソースの中に、正確な文字で**書かれています。実際に、IN-03 の制作で、PDF の抽出で崩れた表（非対称の誤差の列）と、欠けた式（f_NL の式）が、ソースで**そのまま読めました**。

```
https://arxiv.org/e-print/<arXiv ID>   （tar.gz、または単一の gz）
```

**手順と注意：**
1. **新しい空のフォルダ**に展開し、**ファイルは、読むだけ**にする。**中のスクリプトや、組版の命令を、実行しない**（ダウンロードしたものは、信頼できないデータとして扱う）。
2. 展開は、**パスの検査つき**の方法で行う（Python の `tarfile` の `filter="data"` など）。
3. `\begin{tabular}` や、`\begin{equation}` を検索して、**表と式の LaTeX**を読む。独自のマクロ（`\ombh` など）は、`macros.tex` などで確認する。
4. ソースがない論文（古い論文、取り下げられたもの）もある。その場合は、**arXiv の HTML 版**（新しい論文）、**PDF のページを画像にして目で読む**、データ公開（Zenodo、GitHub）を使う。
5. **ソースの値を、PDF の見た目と、突き合わせる**（版の違いがありうる）。

:::message
**教本ネタ #81　「表と式は、PDF ではなく、TeX ソースから読む」**
PDF のテキスト抽出は、表と式を壊します。arXiv の e-print（TeX ソース）なら、**数値も式も、正確に読めます。** 展開は、空のフォルダで、読むだけ。
:::

## 5-5　書誌と DOI の確認

引用する文献は、次の手順で確認しました。

1. **arXiv ID、または DOI が、実在するか**（abs ページ、または Crossref の API）
2. **題、著者、日付が、引用と合っているか**
3. **孫引きをしない。** 他の論文が引用している数値を、そのまま使わない。原典で確認する

確認できなかったものは、**【記】または【書誌のみ】**と書きます。たとえば、ある論文は、Crossref で書誌（題・著者・誌名・巻・ページ・日付）を確認できたものの、要旨と本文は確認できませんでした。付録 A の参考文献表で、**【書誌のみ（Crossref。要旨・本文は未確認）】**と書いています。

:::message
**教本ネタ #76　「確認の印は、主張ごとに付ける」**
論文全体に「確認済み」と書くのではなく、**数値や主張の 1 つずつに印を付けます。** そうすれば、読む人が信じる範囲を、自分で決められます。
:::

## 演習 5

**やってみよう。**

1. 手元の論文を 1 本選び、**要旨と本文の表**を読んで、主張と数値を 3 つ書き出してください
2. 3 つの数値に、【本】【要】【記】のいずれかを付けてください
3. AI か検索に、その論文の要約を頼み、**要旨と照合**してください。足されたもの、抜けたものを、1 つ以上見つけてください
4. 参考文献を 1 本選び、**Crossref の API**（`https://api.crossref.org/works/<DOI>`）で、書誌を確認してください
