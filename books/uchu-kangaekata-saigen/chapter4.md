# 第4章　「検定」と「当てはめ」を分ける

> **この章で学ぶこと**
> 1. **当てはめ**と**検定**は、別のこと
> 2. 独立の検定の定義
> 3. 整理型の論文で、「予言」の代わりに何を書くか

---

## 4-1　なぜ分けるのか

モデルが観測に合う、と言うとき、2 つの意味が混ざっていることがあります。

- **当てはめた**：データに合うように、数を調整した
- **検定した**：調整に使っていないデータで、予言を出し、合うか確かめた

**当てはめて合うのは、当たり前です。** 数を調整したのですから。価値があるのは、**調整に使っていないデータでも合うこと**です。

---

## 4-2　独立の検定の定義

IN-01 は、次の定義を使いました。

```
独立の検定とは：
　当てはめに使ったデータとは別のデータについて、
　当てはめた数値だけで予言を出し、
　観測と比べること。

データを足して当てはめ直すのは、検定ではない。
```

最後の一行が、肝心です。「データを足して、もう一度合わせたら、合った」は、検定ではありません。

---

## 4-3　実例：CMB で決めた 6 つの数を、持ち込む

IN-01 は、ΛCDM の 6 つの数を、**CMB だけで決め**、使っていない観測に持ち込みました。結果の一部です。

| 検定 | 差 |
|---|---|
| ヘリウム 4（BBN） | 0.9σ |
| 物質の量 Ω_m（超新星 対 CMB） | 1.0σ |
| BAO（DESI DR2、13 点） | 2.3σ |
| 動的暗黒エネルギー（DESI+CMB） | 3.1σ |
| ハッブル（SH0ES） | 5.7σ |

（IN-01 の通知表は、全部で 11 個の検定です。）

**この表は、「ΛCDM は合う」でも「合わない」でもなく、「どこで合い、どこで合わないか」を示します。** これが、整理型の論文が出せる、価値です。

:::message alert
**注意：σ の意味**
この表の σ は、**誤差を独立とみなした目安**です。複数の検定は、**独立でない**ことがあります（超新星の較正が、ハッブル定数の議論にも関わる、など）。表の行を並べて、「何個が何σで排除」と数えてはいけません。この注記は、表のすぐ近くに書きます。
:::

---

## 4-4　整理型の「予言」の代わり

『実践編-1』は、**Falsifiable Predictions**（反証可能な予言）の節を、論文の命綱としました。整理型は、新しい予言を主張しません。では、何を書くのか。

**代わりに書くのは、「何が変わると、結論が変わるか」です。**

IN-02 の 9.4 節は、この形で書きました。

| 事象 | 何が変わるか |
|---|---|
| r の検出 | BFT の「インフレーションなし」版と、エキピロティックの「r≈0」が反証される |
| Σm_ν が約 0.059 eV を下回る | 最軽ニュートリノが質量ゼロの模型全般が、圧力を受ける |
| f_NL の誤差が約 1 に縮む | エキピロティックの 2014 年版が、検定可能になる |
| DESI DR3 の BAO | ΛCDM 側の圧力が、どちらに動くか |

**これは、他人の理論の予言を、整理して並べたものです。** 自分の予言ではなく、**将来の観測で、この論文の読みが変わる条件**を書いています。

:::message
**教本ネタ #75　「当てはめと検定を分ける」**
合うことが価値なのではなく、**調整に使っていないデータで合うこと**が価値です。整理型では、「何が変わると結論が変わるか」を、予言の代わりに書きます。
:::

---

## 4-5　自分の結果を、検定として扱わない

整理型の論文には、もう一つ注意があります。**自分の計算を、検定と呼ばないこと**です。

DB-01 では、DESI の BAO の 13 個の数を分解し、「LRG2 を外すと Δχ² が減る」と示しました。しかし、**外す点を、結果を見てから選んでいます**。これは、事後の選別です。**確率的な有意度は付けられません**（第 7 章）。

事後の解析は、**「どの点が効くか」を示す**ものであって、**「この点が犯人だ」と判定する**ものではありません。

## 演習 4

**やってみよう。**

1. 手元の題材で、**当てはめに使ったデータ**と、**使っていないデータ**を、分けて書いてください
2. 使っていないデータで、**当てはめた数だけを使って**、予言を出してください（できなければ、できない理由を書く）
3. 結果の差を、σ（誤差の何倍か）で書いてください。その σ が、**独立でない検定を並べたもの**でないか、確認してください
4. 「何が変わると、結論が変わるか」を、**3 つ**書いてください
