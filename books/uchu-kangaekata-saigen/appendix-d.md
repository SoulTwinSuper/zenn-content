# 付録D　用語集

## D-1　この本の用語

| 用語 | 意味 |
|---|---|
| **整理型の論文** | 新しい理論や予言を主張せず、既存のものを整理し、再現し、比べる論文 |
| **物差し** | 複数の対象を、同じ形で並べるための枠（項目、定義、数え方） |
| **4 層** | 主張を【原理】【計算】【当てはめ】【未知】に分ける分け方（IN-01） |
| **5 項目** | 前提／自由パラメータ／導出される量／予言と照合／層の分類（IN-02） |
| **通知表** | 複数の対象を、5 項目で 1 つの表にしたもの。点数なし。確認の印つき |
| **確認の印** | 【本】本文／【要】要旨のみ／【自】自前の計算／【記】記憶・二次情報／【IN】前の論文で確認 |
| **独立の検定** | 当てはめに使ったデータとは別のデータで、当てはめた数だけで予言を出し、観測と比べること |
| **当てはめ** | データに合うように、数を調整すること |
| **事後の選別** | 結果を見てから、外す点や選ぶ条件を決めること。確率的な有意度は付けられない |
| **併記** | 主張と反論を、そろえて並べ、判定しないこと |
| **履歴版** | X の告知で、シリーズ全体の履歴を、省略なしで載せた長文の投稿 |
| **作業版／公開版** | 作業中の文書（内部用の記述あり）と、そこから作り直した公開用の文書 |

## D-2　宇宙論・統計の用語

| 用語 | 意味 |
|---|---|
| **ΛCDM** | 標準宇宙論。宇宙定数 Λ と冷たい暗黒物質（CDM）。6 つの数で決まる |
| **第 1 原理** | 観測から決めた数を使わず、基本法則だけから導くこと |
| **自由パラメータ** | 観測から決める数 |
| **CMB** | 宇宙マイクロ波背景放射 |
| **BAO** | 重粒子音響振動。距離の物差し |
| **D_M, D_H** | 横方向の距離と、視線方向の距離（BAO） |
| **H₀** | ハッブル定数 |
| **σ** | 標準偏差。差が誤差の何倍か |
| **Δχ²** | χ² の差。当てはまりの良さの比較 |
| **n_s** | 原始ゆらぎのスペクトル指数。1 がスケール不変 |
| **r** | テンソル（重力波）とスカラー揺らぎの振幅の比 |
| **f_NL** | 非ガウス性の大きさ。0 ならガウス的 |
| **N（e-fold）** | インフレーションでの膨張の回数（スケール因子の自然対数） |
| **Σm_ν** | 3 種のニュートリノの質量の和 |
| **RAR** | 放射加速度関係。銀河の加速度の関係 |
| **LRG, ELG, QSO, Lyα** | DESI の BAO のトレーサー（明るい赤い銀河、輝線銀河、クエーサー、ライマンα森） |
| **ゴースト** | 負のエネルギーの自由度。理論の不安定性を示す |

## D-3　登録・組版の用語

| 用語 | 意味 |
|---|---|
| **Zenodo** | 研究データと論文の公開サービス。DOI が付く |
| **DOI** | 論文に付く恒久的な識別子 |
| **arXiv** | 論文のプレプリントサーバ |
| **Crossref** | 論文の書誌の公的なデータベース（API あり） |
| **CC BY 4.0** | 出典を表示すれば、自由に使えるライセンス |
| **BOM** | UTF-8 の先頭の印。日本語を含む PowerShell スクリプトで必要 |
| **DryRun** | 通信せずに、内容だけを表示して確認する実行 |
| **SHA-256** | ファイルの同一性を確かめるための値（ハッシュ） |
| **xelatex** | 日本語を含む文書を組版するための LaTeX の処理系 |
