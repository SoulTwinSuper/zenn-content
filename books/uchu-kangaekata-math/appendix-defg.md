## 付録D　自発的対称性の破れとヒッグス機構

FSCのメキシカンハットポテンシャルの背景理論。

**複素スカラー場のポテンシャル：**

$$V(\varphi) = -\mu^2 |\varphi|^2 + \lambda |\varphi|^4$$

$\mu^2 > 0$ のとき——最小値は $|\varphi| = 0$ ではなく：

$$|\varphi|_{\min} = v = \sqrt{\frac{\mu^2}{2\lambda}}$$

「メキシカンハット」の形——帽子のつばの円上に無数の真空が存在する。

**真空の選択（自発的対称性の破れ）：**

$$\varphi = v + \frac{h + i\xi}{\sqrt{2}}$$

- $h$：ヒッグス場（質量を持つ）
- $\xi$：南部-ゴールドストーン粒子

**ゲージ理論との結合（ヒッグス機構）：**
$\xi$ → ゲージ場の縦波成分に吸収 → ゲージ粒子が質量を獲得

**FSCへの応用：** $\Phi = |\Phi|e^{i\theta}$（Paper F）はこの構造の直接の応用です。

## 付録E　インフレーション理論の基礎

初期宇宙の急膨張を記述する理論。

**スローロール条件：**

$$\varepsilon \equiv \frac{M_{\text{Pl}}^2}{2}\left(\frac{V'}{V}\right)^2 \ll 1, \qquad \eta \equiv M_{\text{Pl}}^2 \frac{V''}{V} \ll 1$$

**インフレーションの終了：** $\varepsilon \approx 1$

**インフレーションの予言：**

- スケール不変なゆらぎスペクトル
- テンソル/スカラー比 $r$
- スペクトル指数 $n_s \approx 0.965$

**FSCとの関係：** FSCのSector IV崩壊は——インフレーション終了後の再加熱（reheating）と類似した構造を持ちます。

## 付録F　統計的検定の基礎

論文の結果を評価するための統計的道具。

### $\chi^2$（カイ二乗）検定

$$\chi^2 = \sum_i \frac{(O_i - E_i)^2}{\sigma_i^2}$$

- $O_i$：観測値
- $E_i$：理論予言値
- $\sigma_i$：観測誤差

自由度 $\nu = \text{データ点数} - \text{パラメーター数}$

**$p$ 値：**

- $p > 0.05$ → 棄却できない（許容）
- $p < 0.05$ → 棄却（理論と観測が不一致）

**規格化 $\chi^2$（reduced $\chi^2$）：**

$$\chi^2_{\text{red}} = \frac{\chi^2}{\nu}$$

| 値 | 意味 |
| --- | --- |
| $\chi^2_{\text{red}} \approx 1$ | 良い一致 |
| $\chi^2_{\text{red}} \gg 1$ | 理論と観測が不一致 |
| $\chi^2_{\text{red}} \ll 1$ | 過適合の疑い |

---

### 信頼区間（ガウス分布の場合）

| 区間 | 意味 |
| --- | --- |
| $1\sigma$（68.3%信頼区間） | $\mu \pm \sigma$ |
| $2\sigma$（95.4%信頼区間） | $\mu \pm 2\sigma$ |
| $3\sigma$（99.7%信頼区間） | $\mu \pm 3\sigma$ |
| $5\sigma$（発見の基準） | $\mu \pm 5\sigma$ |

素粒子物理では——「$5\sigma$」を超えて初めて「発見」と認める慣例があります。

---

### AIC（赤池情報量規準）

$$\text{AIC} = 2k - 2\ln(L)$$

- $k$：パラメーター数
- $L$：最大尤度

「パラメーターが多いほど過適合しやすい」を補正します。

**$\Delta\text{AIC}$ の解釈：**

| $\Delta\text{AIC}$ | 意味 |
| --- | --- |
| $< 2$ | 実質的な差なし |
| $2 \sim 7$ | 有意な差あり |
| $> 10$ | 強い証拠あり |

**BIC（ベイズ情報量規準）：**

$$\text{BIC} = k \cdot \ln(n) - 2\ln(L)$$

$n$：データ点数。AICよりパラメーター数に厳しいペナルティを課します。

---

### FSCの論文における使用例

Paper Dでは——$\Delta H_0 = 2.69$ km/s/Mpc の予言値を示す際に——

「5成分分解の $\chi^2_{\text{red}}$ を将来の課題とする」

と明示しています。

これは——「誠実な限界の明示」の典型例です。

自分の論文を書くとき——$\chi^2$ 統計を計算できない場合は——「将来の課題」として明示することが誠実な態度です。

## 付録G　ベイズ統計の基礎

宇宙論の最前線では——ベイズ統計が標準的です。

### ベイズの定理

$$P(\theta|D) = \frac{P(D|\theta) \cdot P(\theta)}{P(D)}$$

- $\theta$：理論パラメーター
- $D$：観測データ
- $P(\theta|D)$：事後分布（posterior）
- $P(D|\theta)$：尤度（likelihood）
- $P(\theta)$：事前分布（prior）
- $P(D)$：証拠（evidence）

---

### マルコフ連鎖モンテカルロ（MCMC）

高次元のパラメーター空間で事後分布をサンプリングする手法。

宇宙論では——CosmoMC・emcee・Cobaya などのコードが標準的に使われます。

FSCの将来の検証では——MCMC によるパラメーター推定が必要になります。

---

### ベイズ因子（Bayes Factor）

$$K = \frac{P(D|M_1)}{P(D|M_2)}$$

モデル $M_1$ と $M_2$ を比較する指標。

**Jeffreys スケール：**

| $K$ | 意味 |
| --- | --- |
| $K < 1$ | $M_2$ を支持 |
| $1 < K < 3$ | 証拠なし |
| $3 < K < 10$ | 実質的な証拠 |
| $10 < K < 30$ | 強い証拠 |
| $K > 100$ | 決定的な証拠 |

FSC と ΛCDM を比較するとき——このベイズ因子が重要な役割を果たします。
