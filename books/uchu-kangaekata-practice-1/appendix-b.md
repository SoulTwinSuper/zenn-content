# 付録B　教本ネタ索引

## B-1　索引の使い方

```
この索引は——
本文中の「教本ネタ」を
テーマ別に分類したものだ。

講演・授業・執筆の際に——
「このテーマで話したい」
という時に使え。

各ネタには：
・番号
・タイトル
・対応する論文・場面
・本書の参照節

を記した。
```
